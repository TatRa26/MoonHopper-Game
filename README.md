# 🌕 MoonHopper

**MoonHopper** — это добрая 2D платформер-игра на Pygame Zero. Ты управляешь лунным прыгуном, который прыгает по платформам, избегает врагов и собирает волшебное звездное семя. Игра разработана для детей **9–10 лет** — яркая, лёгкая и интересная!

---

## 🎮 Особенности

- Анимированные враги с патрулированием
- Прыгающий герой с гравитацией
- Простое управление
- Музыка и звуки (вкл/выкл)
- Меню с кнопками: Start, Sound, Exit
- Финальный экран благодарности

---

## 📦 Используемые библиотеки

- [`pgzero`](https://pygame-zero.readthedocs.io/) — фреймворк для простых игр на Python  
- `random` — стандартная библиотека Python
